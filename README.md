# 飞流 AI 住宅设计提示词

本仓库保存飞流 AI 住宅设计任务的统一提示词。提示词的正式版本位于 GitHub 的 main 分支。

## 在 Codex 客户端中直接调用

无需安装 Codex CLI、插件或 Skill。新建任务时，把下面的说明、GitHub 提示词链接，以及本次户型图和用户资料一起发给 Codex：

请先读取并完整遵循以下 GitHub 提示词的最新版，再根据我附上的本次户型图和用户资料完成设计。请勿使用旧对话或其他客户的信息。若无法读取或核验最新版，请先停止并告知我。
https://raw.githubusercontent.com/pridecai1989-czh/home-designer/main/feiliu-home-design-prompt.md

建议每次都附上这段说明，明确要求 Codex 读取最新版本，并附上本案材料。

## 正式提示词

[打开 GitHub 上的最新版提示词](https://raw.githubusercontent.com/pridecai1989-czh/home-designer/main/feiliu-home-design-prompt.md)

本仓库目前是公开的，任何拥有链接的人都能查看提示词。请勿在提示词或任务材料中放入密码、访问令牌等机密信息。

## 维护提示词

维护者在 GitHub 上编辑根目录的 feiliu-home-design-prompt.md 并提交到 main。成员下次在 Codex 客户端中提供上面的 raw 链接时，即可要求 Codex 读取更新后的内容。更新提示词不需要成员安装 CLI、下载文件或更新 Skill。

## 可选：安装 Skill 插件

如果团队希望在技能选择器中通过名称调用，可以在客户端安装此仓库提供的 Feiliu Home Design Skill。若不希望成员各自安装或更新，直接在任务中提供上面的 raw 提示词链接即可。
